# Contributing

Open an issue with a concrete bug, measurement, or proposed change. Work on a focused branch and use Conventional Commits. Include relevant tests and update English documentation for user-facing changes. Run `ruff check src tests`, `pytest -q`, `chess-ai smoke-test`, and `python -m build` before opening a PR. CUDA changes should include the GPU name, driver, PyTorch/CUDA versions, peak VRAM, and a reproducible command. Never commit datasets, model weights, credentials, cookies, or browser profiles. Report chess strength with complete W/D/L records and identify whether Stockfish or an opening book was used.
